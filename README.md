# Fernando Torres — Portfólio

Portfólio profissional desenvolvido com **Vue 3, TypeScript, Vite e Tailwind CSS**, apresentando minha experiência, projetos e conhecimentos em **Java, Spring Boot, REST APIs e PostgreSQL**.

🎯 Foco profissional: **Java Developer | Backend Engineer | Full Stack Developer**

🌐 **Portfólio:** em breve

## Tecnologias

* **Frontend:** Vue 3, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS
* **Backend:** Java, Spring Boot, REST APIs, JPA / Hibernate
* **Database:** PostgreSQL
* **Ferramentas:** Git, GitHub, Maven, Docker, Vite

## Projetos

O portfólio apresenta projetos desenvolvidos com foco em aplicações reais, incluindo:

* APIs REST desenvolvidas com Java e Spring Boot
* Modelagem e persistência de dados com PostgreSQL
* Aplicação de arquitetura em camadas
* Validações e regras de negócio
* Integração entre frontend e backend
* Agendamento e processamento de tarefas em background

## Rodando localmente

Clone o repositório e instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível em:

```text
http://localhost:5173
```

## Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```

## Deploy

O projeto pode ser publicado utilizando **Netlify** ou **Vercel**.

Configuração:

```text
Build command: npm run build
Output directory: dist
```

O deploy pode ser integrado diretamente ao GitHub para atualização automática a cada novo push.

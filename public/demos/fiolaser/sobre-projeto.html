Fiolaser · sobre o projeto

Explore 33 procedimentos, disponibilidade por duração, reservas, cancelamentos, gestão de clientes e exportação CSV.

Esta demonstração é uma simulação em JavaScript: os dados ficam apenas neste navegador. Os perfis são públicos e não representam autenticação de produção. Preços, imagens, pessoas e reservas são ilustrativos.

O projeto completo usa Java 21, Spring Boot, PostgreSQL, Flyway, JWT revogável e outbox com Kafka. O backend teve 31 testes aprovados com PostgreSQL real. Esse backend não está conectado a esta página. AWS, Google, pagamentos e mensagens não são acionados pela demo.

As imagens editoriais foram geradas por IA; não representam clientes ou instalações reais.
